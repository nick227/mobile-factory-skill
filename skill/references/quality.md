# Component quality and validation

Inspect type safety, accessibility labels and roles, disabled/loading/error behavior, light/dark rendering, touch targets, keyboard overlap, safe areas, performance, and both Android and iOS behavior.

The v0.1 catalog marks demonstration components as `preview`, not `stable`. The library is a development baseline. Existing test files are scaffolds, not comprehensive native component behavior tests. Automated structural governance tests exist in the factory. Native certification requires additional device execution and visual/interaction review.
